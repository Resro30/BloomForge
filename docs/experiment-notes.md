# Experiment notes

The source asset is an artist-modeled planter with a shallow flower ornament. The `renders/base/` image shows the authored geometry; `renders/depth/` contains its Blender Mist pass. The ComfyUI workflow uses an inverted version of that Mist image for FLUX.1 Depth conditioning. The saved JSON is a workflow configuration; running it requires locally installed model weights, which are not part of this repository.
